# Intel(R) C for Metal Compiler

## Introduction

The Intel(R) C for Metal Compiler (CMC) is an open source compiler that implements the C for Metal (CM) programming language.
CM is a GPU kernel programming language for Intel Graphics (including ARC and Xe).

This document is a starting guide for setting up the development environment, building and using CMC.

Public packages can be downloaded from https://01.org/c-for-metal-development-package. No special access rights or registration required.

CMC compiles CM sources to SPIRV for use with OpenCL or L0 runtimes.

It is optionally used as a FE wrapper library by

* IGC graphics compiler - https://github.com/intel/intel-graphics-compiler

To enable offline compilation from CM sources to binary, the cmc tool requires libocloc as a runtime dependency.

## Building

CMC can be built in two major modes: in-tree and external.

### In-tree build

Download sources for LLVM tree structure:

```shell
cd $ROOT
git clone https://github.com/intel/cm-compiler.git -b cmc_monorepo_110 llvm-project
git clone https://github.com/intel/vc-intrinsics.git llvm-project/llvm/projects/vc-intrinsics
git clone https://github.com/KhronosGroup/SPIRV-LLVM-Translator.git -b llvm_release_110 llvm-project/llvm/projects/SPIRV-LLVM-Translator
```

Now configure and make:

```shell
cd $BUILD
cmake -DLLVM_ENABLE_Z3_SOLVER=OFF -DCLANG_ANALYZER_ENABLE_Z3_SOLVER=OFF -DCMAKE_INSTALL_PREFIX=$INSTALL -DLLVM_ENABLE_PROJECTS="clang" -DLLVM_TARGETS_TO_BUILD="" $ROOT/llvm-project/llvm
make install
```

### External build

For an external build, assume you already have LLVM-11, SPIR-V LLVM translator based on LLVM v11.0 and VC-Intrinsics installed, and that their install folders are known.

Then just configure, specifying cmake install folders for all components:

```shell
cd $CLANG_BUILD
cmake -DCMAKE_INSTALL_PREFIX=$INSTALL -DLLVM_CMAKE_PATH=$LLVM_INSTALL_CMAKE -DLLVMGenXIntrinsics_DIR=$INTR_INSTALL_CMAKE -DSPIRV_TRANSLATOR_DIR=$SPIRV_INSTALL_CMAKE $CLANG_SOURCES
make install
```

### Running the compiler

You may run the compiler to generate SPIRV from CM sources:

```shell
$INSTALL/bin/cmc -march=pvc test.genx.cc -emit-spirv -o test.genx.spv
```

If you have libigc and libocloc in your path, you can run cmc to generate a binary:

```shell
$INSTALL/bin/cmc -march=pvc test.genx.cc -o test.genx.bin
```

### Documentation

CM language and compiler documentation lives under `clang/compute_sdk/docs` and is built with [Sphinx](https://www.sphinx-doc.org/).

To build the HTML documentation:

```shell
python3 -m pip install sphinx
cd $ROOT/llvm-project/clang/compute_sdk/docs
make -f Makefile.sphinx html
```

`make -f Makefile.sphinx html` runs the `autogen` step first (regenerating `internal/autogenerated/*.rstinc` from source) before invoking Sphinx, so prefer it over calling `sphinx-build`/`python3 -m sphinx` directly.

Open `_build/html/index.html` in a browser to view it. Math rendering (`sphinx.ext.imgmath`) additionally requires a LaTeX toolchain (e.g. `texlive-latex-extra`) and `dvipng`.

## Testing

The CMC project contains conformance testing provided by LIT tests. To run them, go to the clang build folder and run

```shell
make check-cmc
```
